# Skills registry

One folder per skill, `SKILL.md` inside. A skill is either a chat command (`/name`) or a scheduled headless run via `scripts/daily-agent.ps1 -Skill <name>`. New schedule = row in `docs/ops/crons.md` first.

| Skill             | Trigger                                                    | Cron / manual                                                 | Inputs                                                                                         | Outputs                                                                                                                     |
| ----------------- | ---------------------------------------------------------- | ------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `task-add`        | «добавь задачу», `/task-add …`                             | manual                                                        | chat description, `tasks/README.md` format, existing IDs                                       | task block in `tasks/TASKS.md` Queue; `b24-tasks-sync --push`                                                               |
| `task-run`        | `/task-run`; daily 09:00                                   | cron (`daily-agent.ps1`) + manual                             | first `ready` task, `CLAUDE.md`, `docs/features/<area>.md`                                     | branch `task/T-NNN-slug` merged to main, task → Done, docs-sync, report `tasks/reports/YYYY-MM-DD.md`, Telegram, B24 mirror |
| `idea`            | «есть идея», «давай обсудим», `/idea`                      | manual                                                        | `docs/features`, `docs/strategy`, `docs/decisions`, `docs/HISTORY.md`, owner answers           | `docs/ideas/YYYY-MM-DD-slug.md`, tasks via task-add, ADR when needed, B24 mirror                                            |
| `docs-sync`       | after a task is Done (task-run step 6), `/docs-sync T-NNN` | inside task-run + manual                                      | task block, diff stat, `docs/features/README.md` path map, `docs/HISTORY.md`                   | Planned → Implemented in `docs/features/<area>.md`, HISTORY entry, pointer fixes, known-drift list update                   |
| `project-checkin` | `/project-checkin`; weekly                                 | cron (Fri, `daily-agent.ps1 -Skill project-checkin`) + manual | git state, `tasks/TASKS.md`, `docs/features`, `docs/ideas`, `b24-tasks-sync --status`, reports | `tasks/reports/checkin-YYYY-MM-DD.md`, drift → draft docs-sync tasks, 2–3 proposed tasks with branch names, Telegram        |
| `seo-research`    | `/seo-research`; Monday 08:00                              | cron (`daily-agent.ps1 -Skill seo-research`) + manual         | `research/seo/competitors.md`, previous reports, `CLAUDE.md`                                   | `research/seo/serp/*`, `research/seo/competitors/*`, `keywords.md`, dated report, draft tasks, Telegram                     |

Process these skills implement: [docs/ops/project-management.md](../../docs/ops/project-management.md).
