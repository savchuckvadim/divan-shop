# local-seo

## Summary

Локальное SEO для шоурума диванов в Аликанте строится вокруг Google Business Profile: по Whitespark 2026 восемь из десяти главных факторов Local Pack идут из GBP (первичная категория, близость, ключевые слова в названии, адрес в городе поиска, открыт в момент поиска, рейтинг, показ адреса, доп. категории), отзывы дают ~20%, поведенческие сигналы ~18%, цитирования только ~7%. Профиль надо вести как гибридный: витрина с адресом + до 20 зон обслуживания по городам/индексам (радиус больше нельзя, не дальше ~2 ч езды). Q&A в GBP уже нет (закрыт 3.12.2025, API 3.11.2025), вместо него Gemini-«Ask Maps» читает отзывы, атрибуты и сайт, поэтому FAQ переезжает на сайт (FAQPage-схема) и в описание/посты. Стимулы за отзывы запрещены и Google (в т.ч. квоты сотрудникам с 17.04.2026), и законом ЕС/Испании (RDL 24/2021, штраф до 4% оборота); работает только системный запрос у всех клиентов после доставки с QR/WhatsApp-ссылкой и ответ на 100% отзывов в течение 48 ч на языке отзыва. Товары в профиле лучше давать через Merchant Center free local listings (доступны в Испании, фактор #70 против #136 у ручных товаров), Pointy/Local Inventory App в Испании недоступен. Городские страницы (Alicante, Torrevieja, Orihuela Costa, Elche, Benidorm) допустимы только с реально уникальным контентом: зоны/сроки доставки, отзывы и фото доставок именно из этого города, локальные FAQ, ссылка из навигации; шаблонные страницы попали под мартовское core update 2026. GBP API (Reviews v4, LocalPosts v4, Performance v1) бесплатны, но требуют заявки Basic API Access и верифицированного профиля 60+ дней с сайтом, квота 300 QPM; до одобрения посты планируются в интерфейсе (нативное расписание с апреля 2026). Первый шаг блокируется отсутствием названия: название влияет на фактор #3, вывеска должна совпадать с GBP при видеоверификации.

## Findings

- **[high]** Whitespark 2026: топ-10 факторов Local Pack — 1) первичная категория GBP, 2) близость к точке поиска, 3) ключевые слова в названии, 4) адрес в городе поиска, 5) открыт в момент поиска, 6) высокий рейтинг, 7) адрес показан, 8) доп. категории, 9) число отзывов с текстом, 10) правильный пин. Веса: GBP ~25%, отзывы ~20%, поведенческие ~18%, on-page ~15%, ссылки ~12%, цитирования ~7%.
  - action: Приоритизировать бюджет времени в этом порядке: категории/название/адрес/часы → поток отзывов → фото и посты → сайт (страница под каждую услугу/город) → ссылки → цитирования (разово + квартальный аудит).
  - evidence: https://whitespark.ca/local-search-ranking-factors/
- **[high]** Название в GBP должно совпадать с реальной вывеской; запрещены тэглайны, локация («near SOHO»), товарные уточнения, если их нет в реальном названии. При этом «ключевые слова в названии» — фактор #3.
  - action: При выборе бренда заложить слово «Sofás» в юридическое/торговое имя и вывеску (например «<Brand> Sofás»), город в название не добавлять. Вывеска нужна до видеоверификации.
  - evidence: https://support.google.com/business/answer/3038177?hl=en ; https://whitespark.ca/local-search-ranking-factors/
- **[high]** Категории: выбирать наименьшее число максимально конкретных («этот бизнес ЯВЛЯЕТСЯ...»). Для шоурума диванов: первичная «Sofa store» (Tienda de sofás), вторичные «Furniture store», «Home goods store», при наличии — «Mattress store»/«Outdoor furniture store».
  - action: Проверить точный список категорий в пикере GBP (ES-локаль); первичной ставить самую узкую, под которую реально идут запросы «sofás alicante».
  - evidence: https://support.google.com/business/answer/3038177?hl=en ; https://pleper.com/index.php?do=tools&sdo=gmb_categories
- **[high]** Гибридный профиль: показывать адрес шоурума + до 20 зон обслуживания по городам/почтовым индексам; радиус задать нельзя; вся зона ≤ ~2 ч езды; изменения модерируются до 48 ч.
  - action: Задать зоны: Alicante, San Juan/Sant Joan, El Campello, Mutxamel, San Vicente, Elche, Santa Pola, Guardamar, Torrevieja, Orihuela Costa, Pilar de la Horadada, Villajoyosa, Benidorm, Altea, Calpe, Alcoy, Murcia (проверить время в пути). Те же города — в areaServed JSON-LD.
  - evidence: https://support.google.com/business/answer/9157481?hl=en
- **[high]** Видеоверификация по умолчанию для новых профилей: один непрерывный дубль — улица/номер дома, постоянная вывеска с точным названием, интерьер, доказательство контроля (открыть дверь, кассу, документы); проверка до 5 рабочих дней. С мая 2026 есть также верификация по звонку/SMS/WhatsApp.
  - action: Сначала повесить постоянную вывеску с финальным названием, потом создавать профиль. Снять видео по чек-листу с первого раза, чтобы не попасть в очередь на повторную проверку.
  - evidence: https://support.google.com/business/answer/14271705?hl=en ; https://slashpost.ai/blogs/google-business-profile/google-business-profile-updates-2026
- **[high]** Отзывы: запрещены любые стимулы (деньги, скидки, подарки), gating (фильтрация недовольных), квоты сотрудникам и просьбы упоминать имя сотрудника (явно с 17.04.2026), массовые отзывы с одного устройства. Разрешено просить всех клиентов без стимулов. Ответы с мая 2026 проходят модерацию.
  - action: Внедрить процесс: после доставки/сборки — WhatsApp/e-mail с короткой ссылкой на отзыв всем клиентам; QR/NFC-карточка в шоуруме; просить (без обязательства) фото дивана в интерьере — «отзывы с фото» фактор #43. Ответ на 100% отзывов ≤48 ч на языке отзыва (es/en/ru/uk шаблоны, вычитанные носителями).
  - evidence: https://support.google.com/contributionpolicy/answer/7400114?hl=en ; https://slashpost.ai/blogs/google-business-profile/google-business-profile-updates-2026 ; https://whitespark.ca/local-search-ranking-factors/
- **[high]** Закон: в ЕС/Испании покупка/фальсификация отзывов запрещена с 28.05.2022 (Omnibus 2019/2161 → RDL 24/2021, ст. 26-27 Ley de Competencia Desleal); штрафы до 4% оборота или 2 млн евро; gating по настроению — недобросовестная практика. Google с 24.07.2026 требует явного раскрытия стимула и на странице, и в разметке Review/AggregateRating, иначе ручные санкции и потеря звёзд в SERP.

## Tools

- **Google Business Profile** — Основной актив локального SEO: категории, зоны, часы, фото, посты, отзывы, товары, метрики. cost: бесплатно. automation: Интерфейс + нативное планирование постов; API (Reviews v4, LocalPosts v4, Performance v1, Business Information) после заявки Basic API Access, профиль 60+ дней, 300 QPM, scope business.manage
- **Google Merchant Center (free local listings)** — Показ товаров шоурума в Search/Maps/Shopping, фактор #70. cost: бесплатно. automation: Merchant API / фид (XML/TSV) генерится node-скриптом из Payload products + local inventory feed; привязка к GBP
- **Google Search Console + GA4** — Клики/показы городских страниц и брендовых запросов, конверсии (звонок, WhatsApp, маршрут, заявка). cost: бесплатно. automation: Search Console API (searchanalytics.query) и GA4 Data API, сервисный аккаунт, еженедельный pull
- **Гео-грид трекер (Whitespark geo-grid / localseotool.io / Local Falcon)** — Позиции в Maps по сетке точек вокруг Alicante и Torrevieja. cost: $0-25/мес. automation: У Local Falcon есть API и Looker Studio; у дешёвых — экспорт CSV
- **Bing Places, Apple Business Connect** — Цитирования #2 и #3 по Испании, Apple Maps для iPhone-экспатов. cost: бесплатно. automation: Bing Places может импортировать из GBP; Apple — вручную
- **Páginas Amarillas, Cylex, Yelp.es, 11811, Opendi, HotFrog, Europages, Informa, Foursquare, Facebook** — Базовые цитирования NAP по Испании. cost: бесплатно (PA premium 50-200 €/мес не нужен). automation: Вручную разово; аудит NAP скриптом (fetch + сравнение строк) раз в квартал
- **Habitissimo, Houzz.es** — Отраслевые каталоги «дом/мебель», трафик и неструктурированные упоминания. cost: бесплатно базово. automation: Вручную; следить за лидами
- **WhatsApp Business** — Контакт в GBP (интеграция 2026), рассылка запроса отзыва после доставки. cost: бесплатно / Cloud API платно за сообщения. automation: WhatsApp Cloud API шаблон «спасибо за покупку + ссылка на отзыв»; триггер — статус сделки «доставлено» в CRM
- **Google Rich Results Test / Schema validator** — Проверка FurnitureStore, Product, FAQPage JSON-LD. cost: бесплатно. automation: Проверка в CI через schema-dts типизацию + curl к validator.schema.org
- **Looker Studio** — Дашборд KPI локального SEO (GBP + GSC + GA4 + грид). cost: бесплатно. automation: Коннекторы GSC/GA4 нативные; GBP — через CSV/Sheets из крона

## Crons

## KPIs

- GBP: показы в Maps и Search (н/н, м/м), доля Maps ≥ 50%
- GBP-действия: маршруты, звонки, клики на сайт, WhatsApp-чаты; конверсия действия/показы ≥ 5%
- Отзывы: всего, средний рейтинг ≥ 4.7, скорость 6-10 отзывов/мес стабильно, доля с текстом ≥ 70%, доля с фото ≥ 25%, конверсия запрос→отзыв ≥ 15%
- Ответы на отзывы: 100%, медианное время ≤ 48 ч
- Гео-грид: средняя позиция по целевым запросам ≤ 3 в радиусе 10 км от шоурума, share of local voice в Torrevieja растёт м/м
- GSC по городским страницам: показы, клики, CTR, позиции по «sofás + город» на 4 языках
- Свежесть контента GBP: ≥ 4 поста/мес, ≥ 12 фото/мес, 0 просроченных офферов
- Товары: число моделей в Merchant Center local listings, показы/клики товаров в GBP
- Цитирования: ≥ 30 листингов, NAP-точность 100%, число неструктурированных упоминаний бренда
- Бизнес: визиты в шоурум по источнику «Google», заявки/продажи по городам, продажи целевых моделей vs план
