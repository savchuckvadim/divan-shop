## Summary

Проверил реальную выдачу по 31 запросу на 4 языках и разобрал 6 ключевых сайтов. Испанская выдача по «sofás + город» занята тремя типами страниц: (1) локальные лендинги валенсийских фабрик и сетей без магазина в городе (sofavalencia.com/tienda-de-sofas-en-alicante, sofacentervalencia.com/sofas-alicante/, centresofasvalencia.com/sofas-torrevieja/, mueblesboom.com/tiendas-de-sofas/{city}/), (2) программные страницы «тип дивана + город» онлайн-магазинов (latiendahome.com/entrega/sofas/alicante/..., bigsofassycolchoness.com, muebles-exterior.com/venta/alicante.html), (3) маркетплейсы Wallapop/Milanuncios (1657 объявлений «sofá cama Alicante»). Единственный сильный местный производитель — sofasalicante.com (Эльче, 1000+ м², 200 моделей, 547 отзывов Google, только ES); в Торревьехе — donbaraton.es (ES/EN/RU, городские лендинги, доставка €19 в день заказа), In&Out/mueblesjbrinas.com (EN/ES, 5 шоурумов, FAQ на лендингах), jewellfurniture.com (furniture packs, Fama). Критическая находка: «Alicante» и «Torrevieja» — это ещё и НАЗВАНИЯ МОДЕЛЕЙ диванов у Leroy Merlin, IdeaHome, Anabel Muebles и у десятков фабрик РФ/Украины, поэтому запросы «диваны Аликанте»/«дивани Аліканте» выдают 100% мусор, а в ES обязательно нужны формы «en Alicante», «tienda de sofás». Русскоязычный спрос реален (ветка 4ru.es «Аутлеты мебели», YouTube «где купить мебель в Торревьехе», estate-spain.com), но ни один магазин кроме Don Baraton не имеет RU-страниц; на украинском конкуренция нулевая. Английский сегмент экспатов ищет не «sofa», а «furniture store/packages Torrevieja», причём в выдаче стоят агентства недвижимости (alegria-realestate.com/en/service/furniture-in-torrevieja, mcbcostablanca.com investor furniture pack) — это канал партнёрств. Терминология покупателей: chaise longue = chaiselongue = cheslong = cheslón (все 4 формы живые), rinconera, sofá cama (apertura italiana / sistema libro), sofá relax/motorizado/eléctrico, asientos deslizantes, modular, 3 plazas / 3+2, sofá de piel/polipiel, tela antimanchas (Aquaclean), sofás a medida, directo de fábrica. Публичных цифр объёма нет — нужен Google Keyword Planner (через Google Ads) или Semrush/Ahrefs с базой ES; ниже даю относительные тиры по косвенным сигналам. Дефолтную локаль надо менять на es: вся коммерческая выдача региона — испаноязычные страницы.

## Tools

- **Google Search Console** — Реальные запросы/показы/позиции по всем 4 локалям; главный источник обратной связи цикла. cost: бесплатно. automation: Search Console API (searchanalytics.query) через service account; node-скрипт scripts/gsc-pull.mjs, квота 1200 запросов/мин на проект — хватает
- **Google Business Profile** — Локальный пакет (map pack) по «tienda de sofás Alicante» — это половина локального трафика и отзывы (у sofasalicante.com 547). cost: бесплатно. automation: Business Profile API (нужна верификация и одобрение доступа к API); минимум — ручной постинг раз в неделю
- **Google Keyword Planner (Google Ads)** — Единственный источник объёмов по ES/EN/RU с гео Alicante. cost: бесплатно без запуска кампаний. automation: Google Ads API KeywordPlanIdeaService (нужен developer token, basic access выдаётся бесплатно); либо ручной экспорт CSV раз в квартал
- **Google Analytics 4 + Google Tag Manager** — Конверсии: форма, WhatsApp-клик, звонок, маршрут до шоурума; сегментация по локали. cost: бесплатно. automation: GA4 Data API через service account; скрипт scripts/ga4-pull.mjs
- **Google Trends (trends.google.es)** — Сезонность по «sofá cama», «chaise longue», «sofás» (только длинные запросы без коллизии с моделями). cost: бесплатно. automation: Официального API нет; неофициальные npm-пакеты нестабильны — использовать вручную раз в квартал
- **Semrush или Ahrefs (Lite)** — Объёмы по google.es, позиции конкурентов, их топ-страницы (latiendahome, donbaraton, sofasalicante). cost: ~€100–140/мес; можно отложить, пока хватает GSC + Keyword Planner. automation: API только на дорогих планах; на Lite — ручной экспорт раз в месяц
- **Wallapop Pro / Milanuncios** — Маркетплейсы стоят в топ-3 по типовым запросам — витрина новых моделей со ссылкой на сайт. cost: Wallapop Pro от ~€20/мес. automation: API нет; ручное ведение 1 раз в неделю
- **Директории и форумы экспатов** — expat.com, Yelp, britishbusinesspagesinspain.es, talkquesada.com, costablancaforum.com, 4ru.es, estate-spain.com — ссылки и трафик из EN/RU сообществ. cost: бесплатно/недорого. automation: ручное размещение один раз + ответы в темах
