# google-stack

## Summary

Весь стек можно поднять бесплатно, но три вещи требуют человека и блокируют остальное: (1) домен и название бренда — без них нельзя подтвердить GSC (DNS TXT для Domain property), создать GBP и Merchant Center; (2) один Google Cloud проект с service account, которому вручную выдают доступ в GSC (Full), GA4 (Viewer) и GBP; (3) сертифицированный CMP с Consent Mode v2 — в Испании/ЕС обязателен, иначе GA4/Ads теряют 15–40% конверсий и ремаркетинг. Автоматизируется скриптами node.js без участия человека: ежедневные снимки GSC (Search Analytics API, 25k строк/запрос, 50k/день на тип поиска, данные с лагом 2–3 дня, окно 16 месяцев), GA4 Data API (200k токенов/день на property — хватит с запасом), CrUX API (150 запросов/мин, p75 LCP/INP/CLS за 28 дней), Clarity Data Export (только 10 запросов/день и 1–3 дня истории — снимать ежедневно), Bing Webmaster REST API + IndexNow, Merchant API (генерация фида из Payload и статусы товаров). GBP Performance API даёт звонки/маршруты/клики на сайт/показы в Maps и поисковые запросы по месяцам, но требует ручной заявки на квоту (GBP старше 60 дней, сайт, до нескольких недель). Google Trends официального API нет (только alpha по заявке, 5 лет данных); Keyword Planner через Google Ads API стал проще (developer token отменён 09.09.2026, MCC не нужен), но KeywordPlanIdeaService заблокирован на уровне Explorer — нужен Basic после brand verification, и без рекламных расходов объёмы приходят диапазонами. Лиды для шоурума считаем в GA4 через GTM как события click_phone, click_whatsapp, form_submit (generate_lead), click_directions и помечаем их key events; офлайн-продажи из CRM догружаем Measurement Protocol (окно 72 часа, EU-эндпоинт region1). Снимки храним в git как JSON по дням (data/metrics/<source>/daily/YYYY-MM-DD.json) плюс config/metrics/targets.json с целевыми запросами и моделями; недельный WoW-отчёт сравнивает 7 дней (T-3…T-9) с предыдущими 7 и с той же неделей 4 недели назад, флагует падения позиций >3, клики −30%, провал CWV, падение лидов и автоматически кладёт draft-задачи в tasks/TASKS.md. Looker Studio остаётся человеку как бесплатная витрина (нативные коннекторы GSC/GA4, но GA4-квоты общие с API — дашборд лучше строить из git-JSON через Google Sheets/BigQuery, а не напрямую из GA4).

## Findings

## Tools

- **Google Cloud проект + service account** — Единая точка доступа для всех Google API (GSC, GA4 Data, GBP, Merchant, CrUX, PSI, Ads, Sheets). cost: бесплатно. automation: Человек один раз: создать проект, включить API (searchconsole, analyticsdata, chromeuxreport, pagespeedonline, merchantapi, businessprofileperformance, mybusinessbusinessinformation, googleads, sheets), создать service account, скачать JSON-ключ в .env.automation (GOOGLE_APPLICATION_CREDENTIALS), создать API key для CrUX/PSI. Дальше всё через googleapis npm.
- **Google Search Console** — Позиции, клики, показы, CTR по запросам/страницам/странам/устройствам; индексация; sitemap; hreflang-ошибки. cost: бесплатно. automation: Search Analytics API (searchconsole.searchanalytics.query), URL Inspection API. Лимиты: 25k строк/запрос, 50k/день на тип поиска, 1 200 QPM, 16 мес истории; inspect 2 000/день. Service account добавить как пользователя Full.
- **Google Analytics 4** — Трафик, поведение, лид-события (click_phone, click_whatsapp, generate_lead, click_directions), key events, офлайн-конверсии. cost: бесплатно. automation: Data API runReport (200k токенов/день, 40k/час), Measurement Protocol для офлайн-лидов (72 ч, region1). ## KPIs

- Средняя позиция и доля в топ-3/топ-10 (Google ES, mobile) по целевым запросам из targets.json — по языкам es/en/ru/uk
- Органические клики на карточки целевых моделей и /catalog (WoW и 4W)
- Число запросов с показами ≥50 в топ-20 (рост семантического ядра)
- Лиды в неделю по типам: click_phone, click_whatsapp, generate_lead (форма), click_directions; lead rate = лиды/сессии
- Квалифицированные лиды и продажи целевых моделей (из CRM через offline-conversions) и стоимость лида, когда появится Ads
- GBP: показы в Maps/Search, звонки, запросы маршрута в шоурум (WoW)
- Core Web Vitals pass rate (p75 LCP≤2.5s, INP≤200ms, CLS≤0.1) по шаблонам PHONE
- Доля проиндексированных целевых URL и отсутствие ошибок hreflang/canonical
- Merchant Center: % одобренных товаров, показы/клики бесплатных листингов
- Clarity: rage/dead clicks на карточках целевых моделей, scroll depth
- Полнота данных: 0 пропусков снимков в _manifest за неделю
- Скорость цикла: среднее время от флага в WoW-отчёте до закрытой задачи
