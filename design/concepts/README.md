# Дизайн-концепты: divan.boutique и divan.group

Прототипы для выбора направления (2026-10-05). Не код сайта: отдельные HTML-страницы без сборки, открываются прямо в браузере. Решение и задачи — в [docs/ideas/2026-10-05-two-storefronts-design-fork.md](../../docs/ideas/2026-10-05-two-storefronts-design-fork.md).

## Как смотреть

- Локально: открыть `boutique.html` или `store.html` в Chrome (нужен интернет только для Google Fonts).
- Внизу слева панель «Дизайн»: направление (Кино / Галерея / Чертёж / Неон), четыре палитры, светлая / тёмная / авто, формы (строгие / скруглённые), ссылки между бутиком и магазином. Язык ES / RU — в шапке. Выбор запоминается в браузере.
- Лучше всего смотреть на большом мониторе (2560+) и на телефоне: оба края проверены.

## Направления

| Направление | Идея | Шрифты | Палитры |
| --- | --- | --- | --- |
| **Кино** («Plano secuencia») | Каждый диван в одной студии, прокрутка как камера. Студийный серый — цвет страницы, титры моноширинным, огромные цифры для размеров и цены. Интро: шторки расходятся от центральной линии | TikTok Sans, Martian Mono | Гранат, Синий час, Вольфрам, Сосны |
| **Галерея** («Sala Blanca») | Сайт как белый выставочный зал: экспонат, настенная этикетка, точка как единственный акцент, одна «окрашенная комната» на странице | Source Serif 4, Source Sans 3 | Сургуч, Чернила, Патина, Эспарто |
| **Чертёж** («Cota Cero») | Каждый диван как комплект чертежей: рамка листа и зоны A–L, размерные линии, штамп с ценой и сроком, линии прорисовываются как у плоттера, фото не двигаются | IBM Plex Sans, Martian Mono, Science Gothic | Латунь, Цианотипия, Чертёжная доска, Сургуч |

| **Неон** («Sofá Club») | Молодёжное направление для обеспеченной аудитории (референс growthejungle.com): чёрная основа, розовый и лайм, Unbounded, пилюли, стикеры, бегущая строка; цвет товара не тонируется, акцент — рамкой | Unbounded, Onest, Martian Mono | Жвачка, Лайм, Вольт, Кислота |

**Решение владельца 2026-10-06:** бутик — «Кино», палитра «Вольфрам» (по умолчанию). Переключатель **«Формы: строгие / скруглённые»** даёт любому направлению вариант в духе shadcn (скругления, кнопки-пилюли, карточки в рамке с мягкой тенью). Все варианты сохранены.

Полные арт-брифы: [briefs/](./briefs/) — включая два направления, которые не собирались (soft, swiss).

## Как это устроено (и почему это задел под темы)

- Одна разметка на страницу, три скина (`skin-*.css`) поверх общего `base.css` и `store.css`. Скин меняет токены (цвета, шрифты, отступы), раскладку секций и характер движения; разметка и контент общие. Так же будет устроен прод: компоненты `@workspace/ui` + тема из токенов.
- Состояние на `<html>`: `data-concept` (тема), `data-palette` (p1–p4), `data-theme` (light / dark, без атрибута — системная), `data-brand` (boutique / store).
- `engine.js` только улучшает страницу: переключатели, корзина, лайтбокс, карусели, «Пройдёт ли в дверь», образцы, доставка по городу, перевод на русский словарём.

## SEO-first правила, которые проверены

Скриншоты и аудит — `node scripts/qa/shoot.mjs` (см. [scripts/qa/README.md](../../scripts/qa/README.md)).

- Весь контент в HTML на испанском; без JavaScript страница полная (скрытого текста 0).
- Интро — CSS-оверлей, раз за сессию, пропускается при `prefers-reduced-motion`; LCP — картинка героя, 0,24–0,5 с в лаборатории.
- Появление при прокрутке касается только картинок и чертежей, текст не прячется.
- Карусели — нативный скролл со scroll-snap, все слайды в DOM; корзина, лайтбокс, меню — `<dialog>`.
- CLS ≤ 0,04 на десктопе и ≤ 0,03 на телефоне на испанском; на русском на телефоне выше (у «Неона» до 0,22) только из-за перевода скриптом в прототипе — в проде язык рендерится на сервере. У «Неона» запасной шрифт с подогнанными метриками.
- Цвет товара не искажается: тонировка `multiply` только на нейтральном фоне или на тёмном товаре; в «Неоне» цвет — рамкой.
- Горизонтального переполнения нет на 390, 1440, 2560.

## Что только для прототипа

- Модели, цены, проекты — примерные данные. Фото — Unsplash и Pexels ([assets/CREDITS.md](./assets/CREDITS.md)); для товаров в проде нужны фото фабрик в едином стиле.
- Перевод на клиенте и только ES / RU; в проде четыре локали из типизированных словарей.
- Кнопки EN / UK, формы, оплата — макет поведения.
