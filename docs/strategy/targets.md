# Цели и юнит-экономика

Обновлено 2026-09-21 по решению владельца.

## Главная гипотеза

Проверяем, **можем ли вообще продавать** диваны через сайт + шоурум в Аликанте. Прибыльность на старте не требуется; допустим минус.

| Уровень | Продаж      | Горизонт      |
| ------- | ----------- | ------------- |
| Минимум | 1 продажа   | первые месяцы |
| Средний | 5 продаж    | суммарно      |
| Хорошо  | 1–2 в месяц | стабильно     |
| Супер   | 5 в месяц   | стабильно     |

Ставки на достижение: минимум подтверждает канал (гипотеза «сайт → визит → покупка» жива); средний оправдывает дальнейшие вложения в контент и локальное SEO; хорошо — включаем платные каналы (ADR-0005); супер — масштаб (второй шоурум, nl/de, найм).

## Модель продаж (ADR-0007, принято)

Своя оплата не подключается. На сайте два CTA:

1. **Связаться с менеджером** — форма/WhatsApp/звонок → лид.
2. **Посмотреть в шоуруме и получить код на скидку** — через регистрацию в личном кабинете: клиент получает персональный код, предъявляет его в шоуруме. Код = измеримый мост онлайн → офлайн и первый шаг к базе клиентов.

## Обратный расчёт (ориентир)

`лидов/мес = продажи ÷ close rate шоурума (10–15%) ÷ lead→visit (30%)`. Для «хорошо» (2 продажи/мес): ≈ 45–65 обращений в месяц, ≈ 12–15 в неделю. Для «супер»: ≈ 110–165 обращений в месяц.

| Метрика                         | «Хорошо» | «Супер» |
| ------------------------------- | -------- | ------- |
| Квалифицированные обращения/нед | 12–15    | 30–40   |
| Регистраций в ЛК с кодом/нед    | 5–8      | 15–20   |
| Визиты шоурума/нед              | 3–5      | 8–12    |
| Close rate                      | 10–15%   | 12–15%  |
