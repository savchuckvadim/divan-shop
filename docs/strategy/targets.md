# Цели и юнит-экономика

Обновлено 2026-09-30: модель изменена на онлайн без шоурума, см. [business-model.md](./business-model.md) и [ADR-0009](../decisions/0009-online-only-no-showroom.md).

## Главная гипотеза

Проверяем, **можем ли вообще продавать** обстановку через сайт с доставкой и сборкой по Коста-Бланке, без шоурума. Прибыльность на старте не требуется; допустим минус.

| Уровень | Продаж      | Горизонт      |
| ------- | ----------- | ------------- |
| Минимум | 1 продажа   | первые месяцы |
| Средний | 5 продаж    | суммарно      |
| Хорошо  | 1–2 в месяц | стабильно     |
| Супер   | 5 в месяц   | стабильно     |

Ставки на достижение: минимум подтверждает канал (гипотеза «сайт → образцы → заказ» жива); средний оправдывает дальнейшие вложения в контент и локальное SEO; хорошо — включаем платные каналы (ADR-0005); супер — масштаб (склад, nl/de, найм).

## Модель продаж (ADR-0009, ADR-0010)

Шоурума нет. Сайт продаёт сам, оплата включается поэтапно:

1. **Сейчас** — цены и корзина открыты, оформление заканчивается заявкой, оплата переводом или по счёту.
2. **После autónomo и фактурации** — Stripe с картами и Bizum на чекауте.
3. **При чеке от 800 €** — рассрочка Aplazame или SeQura.

Якорь доверия вместо зала: бесплатные образцы тканей почтой, размерные схемы с проверкой проёма, доставка с подъёмом и сборкой, прозрачная цена доставки по городу, WhatsApp-видеоконсультация.

## Обратный расчёт (ориентир)

Онлайн-конверсия в мебели 1,2–1,65%. Для «хорошо» (2 заказа/мес) при CR 1,4% нужно ≈ 145 сессий на товарных страницах в месяц по целевым кластерам; для «супер» (5 заказов/мес) ≈ 360. Ведущий индикатор до первых продаж — **заказы образцов тканей в неделю**: они появляются раньше заказов и показывают, что спрос реален.

| Метрика                     | «Хорошо»   | «Супер»    |
| --------------------------- | ---------- | ---------- |
| Заказы образцов/нед         | 4–6        | 12–15      |
| Образцы → заказ             | 15–25%     | 20–30%     |
| Оплаченные заказы/мес       | 2          | 5          |
| Return rate (контр-метрика) | <15%       | <12%       |
| Срок факт vs обещанный      | 95% в срок | 98% в срок |
