# ADR-0007: Модель продаж на старте

**Статус:** accepted · 2026-09-21 (решение владельца)

## Context

От наличия чекаута зависят LSSI ст. 27–28, платёжный провайдер, интеграция рассрочки, события GA4, Verifactu, обратная логистика возвратов. Онлайн-конверсия мебели 1,2–1,65%, шоурум закрывает 8–15%+. Главная гипотеза проекта — «можем ли продавать вообще» (см. `docs/strategy/targets.md`).

## Decision

Своя оплата не подключается. Сайт — лидогенерация с двумя CTA:

1. **Связаться с менеджером** (форма на странице контактов с передачей модели, WhatsApp, звонок) → коллекция `leads` → Bitrix24.
2. **Посмотреть в шоуруме и получить код на скидку** через личный кабинет: регистрация (`customers`, auth-коллекция Payload), персональный код скидки, запись на визит (`showroom-visits`). Код предъявляется в шоуруме и связывает онлайн-лид с офлайн-продажей.

Чекаут и рассрочка — после подтверждения гипотезы (уровень «хорошо» или решение на quarterly-strategy).

## Consequences

- North Star = квалифицированные обращения + регистрации с кодом; key events `generate_lead`, `showroom_visit_request`, `sign_up`.
- Merchant Center free listings работают без чекаута.
- Юр-страницы «Condiciones» пишутся под лидген; при регистрации — согласие на обработку данных и отдельное на рассылки.
- Продажи фиксируются в Bitrix24 по коду скидки (поле в сделке), это источник `data/sales/`.
