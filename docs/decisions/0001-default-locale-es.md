# ADR-0001: Дефолтная локаль и x-default = es

**Статус:** accepted · 2026-09-21

## Context

Сайт запущен с `DEFAULT_LOCALE = "ru"`. Все семь исследований независимо пришли к одному: 100% коммерческой выдачи google.es по региону — испанские страницы; Google для гео Alicante отдаёт es-контент; юридические тексты и договор должны быть на испанском как основная версия (LSSI ст. 27); GBP и реклама работают на es. Дефолтная локаль определяет x-default hreflang, редирект с `/`, язык авто-ответов и порядок словарей.

## Decision

`DEFAULT_LOCALE = "es"`, порядок `LOCALES = ["es", "en", "ru", "uk"]`, x-default → `/es/…`. Редирект с `/` по cookie → Accept-Language → es сохраняется, но краулер без Accept-Language получает es. Русские и украинские версии остаются полноценными (реальный спрос, нулевая конкуренция).

## Consequences

- Задача T-004 (ready). Меняются `locales.ts`, Payload `localization.defaultLocale`, словари не трогаются.
- Существующих данных в БД нет, миграция не нужна. Если появятся до выполнения — контент, введённый как ru-дефолт, надо будет перенести.
- Авто-ответы и шаблоны по умолчанию — es.
