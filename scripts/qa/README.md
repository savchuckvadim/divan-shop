# QA: скриншоты и аудит страниц

`shoot.mjs` открывает страницу в локальном Chrome или Edge (headless, через `puppeteer-core`), прокручивает её сверху вниз и сохраняет кадры по ширине экрана, контактные листы и JSON-сводку. Работает с живым сайтом и с локальными `.html` (прототипы в `design/concepts/`).

Не пакет pnpm-воркспейса: зависимости ставятся отдельно.

```bash
cd scripts/qa && npm i          # один раз: puppeteer-core
node scripts/qa/shoot.mjs --url https://divan.group/es --out design/concepts/_shots/live --name home --widths 390,1440,2560 --audit
```

## Флаги

| Флаг                                      | Что делает                                                                                              |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| `--url`                                   | `http(s)://…` или путь к `.html`                                                                        |
| `--out`, `--name`                         | папка и префикс файлов                                                                                  |
| `--widths 390,1440,2560`                  | ширины вьюпорта; высота подбирается под типичный экран                                                  |
| `--max 12`                                | максимум кадров на ширину (равномерная выборка по высоте страницы)                                      |
| `--scheme dark`                           | `prefers-color-scheme: dark`                                                                            |
| `--lang ru`                               | язык браузера (`navigator.language` и `Accept-Language`)                                                |
| `--reduced`                               | `prefers-reduced-motion: reduce`                                                                        |
| `--nojs`                                  | без JavaScript: проверка, что контент виден без скриптов                                                |
| `--loader`                                | кадры через 150 / 600 / 1100 / 1900 мс после навигации (интро, лоадер)                                  |
| `--click "<css>"`                         | клик после загрузки и один кадр (корзина, лайтбокс, меню)                                               |
| `--attr "data-accent=ink,data-mode=dark"` | атрибуты на `<html>` до первой отрисовки                                                                |
| `--audit`                                 | заголовки, число `h1`, картинки без `alt` и размеров, текст, скрытый в покое, внешние хосты, размер DOM |
| `--full`                                  | дополнительно полный скриншот страницы                                                                  |

В JSON на выходе: высота страницы, горизонтальный перелив в px, ошибки консоли, упавшие запросы, LCP (время и элемент), CLS, объём передачи.

## Где используется

- Прототипы дизайна в `design/concepts/`: сборка, критика, проверка (скриншоты в `design/concepts/_shots/`, папка в `.gitignore`).
- Проверка живого сайта до и после дизайн-задач. Метрики здесь лабораторные (один прогон, без троттлинга); для решений по Core Web Vitals смотреть полевые данные CrUX и Search Console.
